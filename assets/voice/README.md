# Voice-over

ElevenLabs voices for every cutscene line (`src/shared/RelayStory.ts`) and every in-mission radio
line (`src/shared/MissionCatalog.ts`: beats, chatter, twists, hazards, group calls, ace stage/return
lines, plus the server's "pulled back to call his wing" calls). HUD system text is never voiced; the
trainee speaks in cutscenes only.

| File | What it is |
|---|---|
| `casting.json` | Speaker → premade voice, voice settings, model, spoken-form replacements, retakes, accepted STT homophones |
| `lines.json` | Generated by `bun tools/voice-lines.ts`: stable line id, speaker, exact on-screen text, spoken text |
| `voiceBank01-06.ogg` | Upload banks (mono Vorbis, ≤ 6.25 min, 0.25 s silence between lines) |
| `upload-plan.json` | Bank sha256, duration and every line's region |
| `transcripts.json` | Line id → speaker, exact text, spoken text, voice, bank |
| `provenance.json` | Line id → cache key, ElevenLabs request id, plan tier at generation |
| `stt.json` | ElevenLabs `scribe_v1` transcription of each bank; per-line word-match rate |
| `checklists/*.json` | Per-bank moderation pre-check and full transcript for the reviewer |
| `sampler.mp3` / `sampler.json` | One line per character (77 s) |

The game reads `src/shared/VoiceCues.ts` (generated cue table) and `src/shared/VoiceBanks.ts` (bank →
asset id, empty until uploaded; empty means silent). Pipeline and commands: `tools/voice.py --help`.
Raw ElevenLabs takes are cached outside the repo in `~/.skybreak-voice-cache` (keyed by
sha256 of voice + model + settings + text), so an edited line regenerates alone.

Uploading is the coordinator's job, after an independent reviewer writes `review.json`
(format in `tools/upload-voice.py`): `python3 tools/upload-voice.py --dry-run` first.
