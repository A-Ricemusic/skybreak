## 2. Summary

Clear airship-mounted jammers from a fog-bound ravine so a damaged reconnaissance aircraft can navigate home, then defeat the fighters trying to intercept it. The strike phase requires 1,300 points within 7:00 but lets the player continue for rank; 32 jammer kills produce 3,200. The update opens a 15:00 intercept clock; five fighter kills add 480, including a named ace. Total 3,680/S, objective time 9:43.96. Broken Relay replaces reconnaissance intelligence with the harbour master’s paper evidence and Vulture Two’s statement aboard one slow plane.

- Exact fighters’ spawn trigger and named ace’s optional status. Proposed adaptation: four required attackers plus one optional ace; if source-comparison later proves all 5 mandatory, revise before activation.
