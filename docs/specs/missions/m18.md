Baseline **origin/main 088fbfc** (merged engine batch C, #145); this section is a source review, not a Studio observation. M14–M18 modules on main are locked placeholders. Preserve working controls, player aircraft, weapons, mission 1–2 content and release guards.

Rearm currently belongs to a score phase and preserves damage. Separate landing/takeoff HUD clocks and weapon-change presentation need follow-through before reference parity.

Existing route/ground/ace phases are building blocks, not a working vent-run lifecycle. Need single-owner world/environment transition without reload, strict no-other-fire duel and finale remapping.
- **Duel ammunition integration:** retain rack count, special-charge state and regeneration progress through cleanup/staging and the duel; validate no artificial refill and continued regeneration. No finite-ammunition system is required for this duel. A future finite-stock assault would need an explicit phase-policy handoff back to regeneration.

Reference gun rounds, finite missile/special stocks and weapon-select/rearm displays are observations, not existing SKYBREAK capabilities. Batch C rearm alone cannot make finite-ammunition resupply meaningful. Do not claim rack, gun or loadout parity from the present engine.
- **Asset needs:** Original relay-works exterior/interior modules, three distinct generator rooms, central core and roof panels, smoke/damage variants and original Rusk livery. Reuse approved player/enemy jets; create no copied superweapon mesh or textures. These are requests, not uploaded assets. Blender-origin exports/textures must pass independent exact-file/material/UV/all-angle review against current official Roblox Terms and Community Standards, explicit project 10/10 safety verdict, hashes and dependency manifest before any Roblox upload.
