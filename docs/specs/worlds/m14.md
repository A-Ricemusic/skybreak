## 5. Lighting and atmosphere

Night; briefing clock 02:56, cloud 10% / 14,000 ft / cirrus (Ci, 3:19:37); ice describes the surface environment. Use the reference windows above to compare horizon, silhouette contrast, cloud mass and water/ground luminance. Start from existing environment presets, then author a mission-owned override rather than altering shared weather for earlier missions. The world/environment owns lights and effects once; mission data must not create a second lighting owner. Night targets need legibility without daytime ambient brightness. Storm smoke and rain must not erase route-entry/exit cues or exceed mobile effects budgets. No audio listening was performed, so ambient sound design remains a separate original task.
